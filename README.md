# Invent a Word We Need

[![Invent a Word We Need](https://make.fun/badge/u-deranalabs-invent-a-word-we-need-17a020e0.svg)](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0)

A tiny program for [Invent a Word We Need](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0) bounty on [make.fun](https://make.fun).

It writes one line to `/output/entry.txt` — one newly invented English word and its definition in a single line:

> tabnesia — opening a browser tab, then staring at it, having already forgotten what you meant to look up.

Run it with:

```sh
python3 main.py
```
